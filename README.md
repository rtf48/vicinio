# Restaurant Waitlist Application

A modern, responsive web application for managing restaurant waitlists with real-time wait time calculations.

## Features

### Core Functionality

- Allows users to add and remove parties from the waitlist; records name and party size
- Automatically calculates and displays the duration each party has been waiting
- Estimates wait time for new parties based on rolling average of wait times and queue length


### Prerequisites

- Python 3.7 or higher
- pip (Python package manager)

### Setup Instructions

1. **Clone or download the project**:

   ```bash
   git clone https://github.com/rtf48/vicinio.git
   cd vicinio
   ```

2. **Install dependencies**:

   ```bash
   python3 -m pip install -r requirements.txt
   ```

3. **Run the application**:

   ```bash
   python3 app.py
   ```
